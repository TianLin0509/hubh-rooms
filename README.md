# 抢会议室

WeLink 会议室每天 12:00 放号自动抢订

AI HUB-H 小工具之一：从 AI HUB-Huawei 拆出的单一功能，不需要安装 AI HUB，也不调用任何 AI 模型。

## 安装

在 [Releases](https://github.com/TianLin0509/hubh-rooms/releases/latest) 下载：

- `HUBH-Rooms-Setup-<版本>.exe`：双击安装（装在当前用户目录，不需要管理员权限），桌面和开始菜单会出现「抢会议室」。
- `HUBH-Rooms-<版本>-win-x64.zip`：免安装版，解压后双击 `抢会议室.exe`。

## 更新

程序内「设置 → 版本与更新」一键更新：只下载变化的程序文件（通常不到 1 MB），重启即生效，不用重装。
更新源依次为阿里云高速、阿里云、GitHub，任一可用即可。

## 数据

设置和记录只保存在本机 `%APPDATA%\HUBH-Tools\rooms`，卸载时保留。
